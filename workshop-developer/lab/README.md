# KKP Merchant Support Platform

Internal workspace: the Settlement Desk payout job, the help-center docs,
and the IBM Bob configuration for this project.

- `server.mjs` + `data.json` + `test/` — the Settlement Desk daily payout job
- `docs/` — the official refund policy and payout schedule
- `src/payout.js` — payout helpers used by the support tooling
- `backups/` — last known-good `.bob` configuration snapshot (pre-v2.3.0)
- `.bob/`, `.bobignore`, `AGENTS.md` — IBM Bob configuration for this workspace

Maintained by the Merchant Support Platform team.
