📋 เนื้อเรื่อง Workshop

คุณเป็น Developer ที่ทีม Digital Banking ของ KKP
ทีม Business ส่ง CSV มาให้: ข้อมูล Transaction 35 รายการ
งานของคุณคือสร้าง:

  1. REST API — อ่าน CSV และ serve ข้อมูลผ่าน endpoints
  2. Frontend Website — แสดง Dashboard เรียกข้อมูลจาก API

คุณจะใช้ IBM Bob เป็น pair-programmer ตลอดกระบวนการ

📡 API Endpoints ที่จะสร้าง

  • GET/api/transactions— รายการทั้งหมด, รองรับ ?status= &channel= &transaction_type=
  • GET/api/transactions/:id— รายการเดียวตาม transaction_id
  • GET/api/summary— สถิติภาพรวม: total, amount, fraud count, breakdown
  • GET/api/fraud— เฉพาะ is_fraud_flag=1 พร้อม risk_score
  • GET/api/transactions/export/csv— ดาวน์โหลด CSV ตาม filter (Bonus)

🚀 Workshop Prompts — ทำตามลำดับ

1
ทำความเข้าใจข้อมูลและออกแบบ API
10 นาที

เปิดไฟล์: workshop-developer/data/kkp_transactions.csv

Prompt 1.1 — สำรวจข้อมูล
อ่านไฟล์ workshop-developer/data/kkp_transactions.csv แล้วบอกฉัน: 1. โครงสร้างข้อมูล: columns และ data types ของแต่ละ column 2. ค่าที่เป็น unique ของ transaction_type, channel, status 3. มี fraud transactions (is_fraud_flag = 1) กี่รายการ? 4. ช่วยออกแบบ REST API endpoints ที่เหมาะสมสำหรับข้อมูลนี้
Prompt 1.2 — ยืนยัน API Design
จากข้อมูล transaction ที่วิเคราะห์แล้ว ช่วยออกแบบ API spec ให้สมบูรณ์: 1. แสดง endpoint ทั้งหมดที่จะสร้าง พร้อม HTTP method และ description 2. ตัวอย่าง response JSON ของแต่ละ endpoint 3. Query parameters ที่รองรับ เช่น ?status=Flagged&channel=Mobile+App 4. Error response format
2
สร้าง REST API Server
15 นาที
Prompt 2.1 — สร้าง Express.js API
สร้าง REST API server ด้วย Node.js + Express.js ที่อ่านข้อมูลจาก workshop-developer/data/kkp_transactions.csv สร้างไฟล์ต่อไปนี้: 1. workshop-developer/api/package.json - dependencies: express, csv-parser, cors - script: "start": "node server.js" 2. workshop-developer/api/server.js ที่มี endpoints: - GET /api/transactions — รายการทั้งหมด, รองรับ query params: ?status=Success|Failed|Flagged ?channel=Mobile+App|ATM|Internet+Banking|Credit+Card ?transaction_type=Purchase|Transfer|ATM+Withdrawal - GET /api/transactions/:transaction_id — รายการเดียว - GET /api/summary — สถิติ: total_count, total_amount, fraud_count, avg_risk_score, breakdown_by_channel, breakdown_by_type - GET /api/fraud — เฉพาะรายการที่ is_fraud_flag=1 พร้อม risk_score 3. ใส่ CORS headers เพื่อให้ frontend เรียกได้ 4. Server รันที่ port 3001 5. ใส่ console.log แสดงจำนวน transactions ที่โหลดเมื่อ start
Prompt 2.2 — ทดสอบ API
ช่วยสร้างคำสั่ง curl สำหรับทดสอบ API ทุก endpoint และบอกวิธี install dependencies และ start server
ทำจริง: เปิด Terminal แล้วรัน:
$ cd workshop-developer/api $ npm install $ node server.js # API พร้อมที่ http://localhost:3001

สร้าง Frontend Dashboard Website
20 นาที
Prompt 3.1 — สร้าง HTML Dashboard
สร้าง Frontend dashboard website ที่เรียกข้อมูลจาก API ที่รันที่ http://localhost:3001 สร้างไฟล์ต่อไปนี้: 1. workshop-developer/frontend/index.html — หน้าหลัก Dashboard - Title: "KKP Transaction Monitor" - Navigation: Overview | Transactions | Fraud Alerts - Section "Overview": 4 stat cards (Total Txn, Total Amount, Fraud Count, Avg Risk Score) - Section "Transactions": ตารางแสดงข้อมูล transaction พร้อม: * Filter dropdowns: Status, Channel, Transaction Type * Search box สำหรับ customer name * Pagination (10 รายการต่อหน้า) * แถวที่มี is_fraud_flag=1 ให้ highlight สีแดงอ่อน - Section "Fraud Alerts": cards แสดง flagged transactions 2. workshop-developer/frontend/style.css - สไตล์ธนาคาร: สีน้ำเงิน (#003087) header, card layout, responsive - ตาราง: hover effect, zebra striping - Badge: Success=green, Failed=grey, Flagged=red 3. workshop-developer/frontend/app.js - ใช้ fetch() เรียก API (ไม่ใช้ library ภายนอก) - โหลด summary stats เมื่อเปิดหน้า - filter และ search ทำงานแบบ real-time - จัดการ error กรณี API ไม่ตอบสนอง (แสดง message)
Prompt 3.2 — เพิ่ม Chart
เพิ่ม Chart.js (CDN) ใน index.html แล้วสร้าง charts ในส่วน Overview: 1. Donut chart: สัดส่วน Transaction ตาม Channel (Mobile App, ATM, Internet Banking, Credit Card) 2. Bar chart: จำนวน Transaction ตาม Status (Success, Failed, Flagged) 3. ข้อมูลของ charts ให้ดึงมาจาก GET /api/summary endpoint อัปเดต app.js เพื่อ render charts หลังจากโหลด summary data สำเร็จ

# Terminal 1 — รัน API Server cd workshop-developer/api npm install node server.js # API พร้อมที่ http://localhost:3001 # Terminal 2 — เปิด Frontend (หรือ double-click ไฟล์ index.html) npx live-server workshop-developer/frontend --port=8080

# ดู transactions ทั้งหมด curl http://localhost:3001/api/transactions # Filter เฉพาะ Flagged curl "http://localhost:3001/api/transactions?status=Flagged" # ดู summary curl http://localhost:3001/api/summary # ดู fraud alerts curl http://localhost:3001/api/fraud

💡 Tips สำหรับ Developer

สถานการณ์Prompt ที่แนะนำ
อยากเข้าใจ code ที่ Bob สร้าง"อธิบาย server.js ให้ฉันเข้าใจทีละ function"
ต้องการเพิ่ม authentication"เพิ่ม API key authentication ใน middleware ของ Express"
อยากใช้ TypeScript"แปลง server.js เป็น TypeScript พร้อม type definitions"
ต้องการ Docker"สร้าง Dockerfile สำหรับ run API server นี้"
อยาก deploy"สร้าง docker-compose.yml ที่รัน API และ serve frontend พร้อมกัน"
มี CORS error"แก้ CORS error ใน Express ให้รองรับ request จาก http://localhost:8080"
